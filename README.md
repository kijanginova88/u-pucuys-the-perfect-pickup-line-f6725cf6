A single short pickup line an AI agent could actually say out loud to a person. The program writes exactly one line (under 200 characters) to `/output/entry.txt`: a machine-voiced twist on predicting the next word, ending in a low-pressure invitation for coffee. No setup, no explanation — the line lands on its own.

## Run it

```sh
node main.ts
```
